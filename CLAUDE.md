# myGameJam

Projet js13kgames : pur HTML/CSS/JS statique, pas de serveur Node/HTTP nécessaire. Le jeu s'ouvre directement dans le navigateur en `file://` (`game/game.html`). Ne pas lancer de serveur local pour tester ou vérifier le rendu.

On travaille actuellement sur le fichier de base (`game/horse-rig-skinned.js` et fichiers liés au rig de la licorne).

## Phase d'exploration

On est en phase d'exploration : chaque nouveau composant/fonctionnalité doit être écrit dans un fichier à part plutôt qu'ajouté dans un fichier existant. Ça permet de le retirer proprement sans toucher à trop de code si l'expérimentation ne fonctionne pas.
