# Rainbow Hoof

A Mario-like 2D platformer starring a rigged horse. Run, jump, and collect
magic horns to unlock seven different rainbow-colored powers as you race
across the level to the finish line.

## Controls

| Action | Key |
|---|---|
| Move left | A |
| Move right | D |
| Jump | Space |
| Activate held power-up | E |
| Fire (red power-up only) | I |

All keys are rebindable from the Options menu.

## Power-ups

Horn boxes scattered through the level give you a random magic horn. You
carry one at a time (shown top-right) and unleash it with **E**:

| Color | Effect |
|---|---|
| Red | Arms a shot — press I to fire a projectile |
| Orange | Next jump is a super jump |
| Yellow | Temporary invincibility |
| Green | Restores one heart |
| Blue | Temporary speed boost |
| Indigo | Temporary shrink (helps dodge tight spots) |
| Violet | Temporary "eat monsters" — touching a weak enemy destroys it and repairs a broken heart slot instead of hurting you |

## Lives

You start with 3 hearts. Weak enemies and hazards cost you a heart on
contact; tougher enemies destroy a heart slot outright (shrinking your
max), which only the violet horn's monster-eating effect can repair. Green
horns simply refill an existing heart. Lose all hearts and it's game over.

## Goal

Platform, dodge enemies, and reach the finish line at the end of the level.
